직캠 관리 앱

동일 장비의 중복 대여 방지

상황대여 가능 여부를 먼저 조회한 뒤 상태를 변경하는 방식이라면, 두 요청이 동시에 같은 장비를 '대여 가능'으로 판단할 위험이 있습니다.

해결 방법대여 가능한 상태인 경우에만 변경하도록 UPDATE의 WHERE 조건을 구성했습니다. UPDATE 영향 행 수가 1이면 성공, 0이면 대여 실패로 판단해 요청 결과를 구분했습니다.

결과경쟁하는 대여 요청 중 실제로 상태 변경에 성공한 요청만 대여 처리하도록 구현했습니다.

와트매니저2

계층형 체크리스트 관계 유지

상황상위·하위 항목이 연결된 체크리스트 템플릿을 복제할 때 PK가 새로 생성됩니다. 기존 부모 ID를 그대로 사용하면 복제된 항목들의 계층 관계가 어긋날 수 있었습니다.

해결 방법복제 과정에서 기존 ID와 신규 PK의 대응 관계를 관리했습니다. 이 매핑을 사용해 하위 항목의 부모 참조를 복제된 상위 항목의 신규 PK로 연결했습니다.

결과템플릿을 복사하더라도 부모·자식 관계를 유지하는 기능을 구현했습니다.

기존 시스템 기술 환경

Maven 의존성 충돌 해결

상황eGovFramework 3.x에서 4.0으로 단계적으로 올리는 과정에서 라이브러리 버전 충돌과 설정 파일 호환성 문제가 발생했습니다.

해결 방법Maven 의존성 버전을 조정하고 exclusions를 적용해 충돌하는 라이브러리를 제외했습니다. 단계별 업그레이드 과정에서 설정 파일 호환성도 확인하며 문제에 대응했습니다.

결과마이그레이션 작업 중 발생한 의존성·설정 문제를 해결했습니다. 다만 결과물은 최종 운영 환경에 반영되지 않았습니다.

기존 시스템 미디어 처리

영상 재생 호환성 개선

상황기존 첨부 기능을 영상까지 확장하는 과정에서 HEVC(H.265) 코덱 영상의 웹 재생 호환성을 고려해야 했습니다.

해결 방법ffprobe로 업로드된 영상의 코덱을 판별하고, 변환이 필요한 경우 FFmpeg를 이용해 H.264 MP4 형식으로 변환하는 처리를 구현했습니다.

결과웹 환경에서 재생 가능한 형식으로 변환하는 기능을 제공해 영상 호환성 문제에 대응했습니다.

출입 신청 시스템

서버 기준 안전교육 이수 판정

상황안전교육 이수 가능 시각을 사용자의 기기 시간으로 판단하면 기기별 시간 차이나 임의 변경으로 판정 기준이 달라질 수 있습니다.

해결 방법클라이언트 시간에 의존하지 않도록 서버 기준으로 이수 가능 시각을 계산하고 저장한 뒤, 이후 요청 시 현재 서버 시간과 비교해 이수 여부를 검증했습니다.

결과안전교육 이수 여부를 일관된 서버 시간 기준으로 처리하는 업무 로직을 구현했습니다.
